• One click run

• Zero dependencies (other than having Python installed)




What's new in this version?




• Added ability to save as a .bbox project file that recovers app states

• Added Undo / Redo options

• All Undo / Redo states are saved in project files (you can quite literally save the undo's all the way back to the start even)

• Added ability to increase size of right panel text fields by dragging the bar under the fields

• Simplified the editable Width / Height values (resolution in the dropdown preset resolutions are still editable directly too)

• Rearranged and polished various UI elements

• Added Lock options to bounding box behavior (position / size / aspect ratio locks, but will still be resized when colliding against the boundaries of the canvas)

• Added menu options when right clicking the canvas, including changing the background, changing the grid style, scaling options, and a recentering option for the canvas.
